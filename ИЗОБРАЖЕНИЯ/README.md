# ИЗОБРАЖЕНИЯ

Здесь хранятся визуальные материалы GeraKProtocol.

Папка предназначена для:

- символа GeraKProtocol;
- Social Preview;
- иллюстраций документации;
- других фирменных визуальных материалов.

## Рекомендуемая структура

```text
ИЗОБРАЖЕНИЯ/
├── README.md
├── gerakprotocol-symbol.svg
├── gerakprotocol-social-preview.png
└── ...
```

Названия можно изменить, если выбранная система хранения лучше подходит конкретному материалу.

## Символ GeraKProtocol

Символ должен работать без обязательного текстового сопровождения.

Желательные варианты:

- SVG для масштабируемого использования;
- PNG для случаев, где SVG неудобен;
- версия для светлого фона;
- версия для тёмного фона;
- компактная версия для маленьких размеров.

Символ не должен быть привязан только к README.

Актуальные файлы: [SVG-исходник](gerakprotocol-symbol.svg), [PNG-символ](gerakprotocol-symbol.png) и [Social Preview](gerakprotocol-social-preview.png).

Он должен подходить для:

- аватара GitHub;
- Social Preview;
- документации;
- бейджей;
- крупных визуальных блоков;
- будущих материалов GeraKProtocol.

## Social Preview

Для Social Preview желательно использовать:

- символ;
- название GeraKProtocol;
- короткий подзаголовок;
- достаточно свободного пространства;
- хороший контраст;
- узнаваемую композицию.

Не нужно превращать Social Preview в рекламный баннер.

## Правила хранения

- исходный SVG сохраняется отдельно;
- растровые версии не заменяют исходник;
- не хранить дубли одного и того же изображения без причины;
- использовать понятные имена файлов;
- не добавлять изображения только ради заполнения README.

> **Изображение должно усиливать документацию, а не заменять её.**

Символ и Social Preview хранятся раздельно: квадратный знак используется как самостоятельная иконка, а горизонтальный PNG — для превью репозитория. Растровые версии оптимизируются и не должны превышать 1 МБ.

> Сначала узнаваемый образ. Потом всё остальное.

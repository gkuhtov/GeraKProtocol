# СХЕМЫ

Здесь хранятся визуальные схемы GeraKProtocol, которые используются в документации и README.

Папка предназначена для материалов, которые удобнее хранить как отдельные SVG или изображения, чем описывать только через Mermaid.

Планируемые материалы:

- карта экосистемы;
- архитектурные схемы;
- дополнительные диаграммы связей;
- версии схем, если их потребуется фиксировать отдельно.

> Схема должна объяснять структуру, а не просто занимать место.

# CHANGELOG

История изменений самого GeraKProtocol.

Формат версий: **MAJOR.MINOR.PATCH**.

---

## [1.0.0] · 2026-10-07

### Создано

- первая стабильная версия GeraKProtocol;
- описание границ и принципов протокола;
- каталог экосистемы;
- архитектурная модель;
- описание фирменного стиля;
- история;
- терминология;
- FAQ;
- структура документации;
- отдельные SVG-схемы экосистемы и архитектуры.

### Важно

GeraKProtocol является независимой документацией.

Он не является библиотекой, SDK, framework, package или runtime dependency.

---

## [1.1.0] · 2026-10-30

### Добавлено

- принцип разделения успешной CI-сборки, автоматических тестов, установки и проверки на целевом устройстве;
- рекомендация указывать фактически выполненный уровень проверки без преувеличения результата;
- пример платформенной проверки Android TV: D-pad, фокус элементов и запуск приложений;
- соответствующие пункты в чек-листе целостности документации.

### Важно

Успешная сборка в CI не считается подтверждением работы приложения на физическом устройстве. Платформенные примеры не становятся универсальными требованиями для остальных проектов.

---

## Формат изменений

Будущие версии должны по возможности разделяться на:

- **Добавлено**;
- **Изменено**;
- **Исправлено**;
- **Удалено**;
- **Важно**.

Не каждое редакционное изменение требует отдельной записи.

История нужна для значимых изменений модели протокола и документации.

> **Не каждый коммит обязан попасть в историю. Только те, которые меняют картину.**
